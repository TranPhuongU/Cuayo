
### 🐦 Cuayo – Flappy Bird–Style Arcade Game (Mobile)
- A Flappy Bird–style 2D mobile arcade game featuring one-tap controls with humorous meme-inspired visual and sound effects.  
- Implemented gravity-based movement, obstacle spawning, collision handling, and score tracking.  
- Tested and validated UI and performance on mobile devices.
